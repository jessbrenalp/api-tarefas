# API Tarefas

API REST para gerenciamento de tarefas desenvolvida com Java e Spring Boot.

## 🚀 Tecnologias

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- Git/GitHub

## ⚙️ Funcionalidades

- Criar tarefas
- Listar tarefas
- Atualizar tarefas
- Excluir tarefas
- Validação de dados
- Integração com banco de dados

## 🏗️ Arquitetura

O projeto utiliza uma arquitetura organizada em camadas:

Controller
Service
Repository
Entity

## 📌 Objetivo

Projeto desenvolvido para praticar desenvolvimento de APIs REST,
CRUD, persistência de dados e integração com banco de dados.
